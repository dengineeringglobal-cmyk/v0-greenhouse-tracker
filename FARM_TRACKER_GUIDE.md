# Farm Tracker - Comprehensive Farm Management System

Farm Tracker is a complete farm management solution designed to help you track crops, monitor harvests, manage expenses, and optimize your agricultural operations.

## Getting Started

### Login
1. The system initializes with a demo admin account
2. Click "Login as Demo User" on the login page to access the system
3. You can then create additional users and manage the system

## Features

### Dashboard
- **Quick Overview**: View key metrics including active crops, harvests, expenses, and recent activities
- **Charts & Analytics**: Visual representations of harvest trends, crop status, and expense data
- **Recent Activities**: Track the latest farm operations

### Farms Management
- Create and manage multiple farm properties
- Track farm location, total area, and ownership
- Switch between farms seamlessly
- View all farms in a grid layout with key information

### Crops Management
- Add crops with detailed information:
  - Crop name and variety
  - Planting and estimated harvest dates
  - Cultivation area
  - Status tracking (Planning, Growing, Harvesting, Completed)
  - Notes for special observations
- Track crop lifecycle from planning to harvest
- Monitor crop age and growth progress
- Delete crops as needed

### Activities Tracking
- Log farm operations including:
  - Fertilizing
  - Irrigation
  - Pest control
  - Pruning
  - Other activities
- Record activity date, description, and detailed notes
- Filter activities by type and crop
- Maintain complete operation history

### Harvest Records
- Record harvest details:
  - Harvest date and quantity
  - Units (kg, lbs, metric tons, units/pieces)
  - Grade classification (A, B, C)
  - Destination (Market, Processor, Storage)
  - Additional notes
- View harvest summary metrics:
  - Total harvested quantity
  - Number of harvest records
  - Average grade
- Track yield trends over time

### Expense Management
- Record all farm expenses:
  - Multiple categories (Seeds, Fertilizers, Pesticides, Labor, Equipment, etc.)
  - Amount and date
  - Detailed descriptions
  - Additional notes
- View expense summary:
  - Total expenses
  - Total number of entries
  - Average expense per entry
- Analyze top expense categories with visual breakdown
- Track expense trends for better budgeting

### Reports & Analytics
- **Comprehensive Reporting**: Generate detailed farm reports
- **Charts & Graphs**:
  - Monthly harvest trends (line chart)
  - Monthly expenses (bar chart)
  - Crop status distribution (pie chart)
  - Top expense categories (bar chart)
- **Summary Tables**:
  - Crops overview
  - Recent harvest records
- **Export Options**:
  - Export data to Excel spreadsheet
  - Print reports for records
- **Detailed Metrics**: View all key performance indicators

### Weather & Agricultural Tips
- **Weather Monitoring Reminder**: Key climate parameters to monitor
  - Optimal temperature range (20-25°C)
  - Humidity levels (60-70%)
  - Rainfall tracking
  - Growth season monitoring
- **Categorized Tips**:
  - Irrigation best practices
  - Pest control methods
  - Fertilization strategies
  - General farm management
- **Daily Checklist**: Recommended daily farm tasks
- **Weekly Tasks**: Important weekly activities
- **Source Attribution**: Learn from trusted agricultural sources

### User Management
- Create new user accounts
- Assign users to specific farms
- Set user roles (Admin, Farm Staff)
- View user details and assignment status
- Track when users were added to the system

### Settings
- View and manage account information
- See current farm details
- Configure system preferences:
  - Email notifications
  - Data backups
  - Weather alerts
- About the system and version information

## Data Storage

Farm Tracker uses browser localStorage for data persistence:
- All data is stored locally on your device
- Data persists across browser sessions
- Export to Excel for backups and sharing
- Clear browser cache to reset the system

## Tips for Success

### Daily Operations
1. **Check the Dashboard** every morning to review current status
2. **Log Activities** immediately after performing farm operations
3. **Monitor Weather** and follow the seasonal tips
4. **Track Harvests** with accurate dates and quantities
5. **Record Expenses** to maintain accurate financial records

### Weekly Tasks
1. Review crop progress
2. Plan maintenance and pesticide applications
3. Inspect greenhouse/farm structures
4. Update records and review metrics
5. Check expense summaries for budgeting

### Monthly
1. Generate reports for analysis
2. Review trends in harvest and expenses
3. Plan next month's activities
4. Backup data by exporting to Excel
5. Verify all records are complete and accurate

## Data Management

### Backup Your Data
1. Go to Reports page
2. Click "Export Excel" button
3. Save the file to your computer
4. Keep multiple versions for historical records

### Import Data
Currently, the system supports manual entry. For bulk imports:
1. Create entries through the interface
2. Or contact support for data migration assistance

## Troubleshooting

### Data Not Saving?
- Check browser's localStorage availability
- Clear browser cache and try again
- Ensure JavaScript is enabled

### Can't See Recent Changes?
- Refresh the page (Ctrl+R or Cmd+R)
- Clear browser cache
- Try a different browser

### Export Not Working?
- Ensure pop-ups are allowed
- Check browser's download settings
- Try a different browser
